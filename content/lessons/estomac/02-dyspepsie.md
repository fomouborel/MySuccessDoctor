## 1. Dyspepsie

**Dyspepsie** = symptômes centrés sur la région **épigastrique (sus-ombilicale)** : douleur ou brûlure épigastrique, plénitude post-prandiale, satiété précoce.

- **Organique** : ulcère, cancer, médicaments (AINS), etc.
- **Fonctionnelle** : symptômes **chroniques** (présents depuis ≥ 3 mois, critères de Rome) **avec une endoscopie normale**. C’est la cause la plus fréquente de dyspepsie.

> Pour parler de dyspepsie **fonctionnelle**, il faut les deux : **chronicité** ET **endoscopie normale**. Pas d’endoscopie → pas de diagnostic ; lésion visible → pas fonctionnelle.

Prise en charge de la dyspepsie fonctionnelle : explication, rassurance, recherche et éradication d’H. pylori, IPP ou prokinétiques selon le symptôme dominant, antidépresseurs à faible dose (neuromodulation).

## 2. Quand faire une endoscopie ?

| Endoscopie justifiée | Pas d’endoscopie d’emblée |
|---|---|
| **Signes d’alarme** : amaigrissement, dysphagie, vomissements répétés, anémie, hémorragie, masse | Patient·e **jeune** avec symptômes typiques **sans signe d’alarme** → traitement d’épreuve (IPP) et/ou recherche non invasive d’H. pylori |
| Âge ≥ 45–50 ans (seuil enseigné : 45 ans) | |
| Échec du traitement (ex. pyrosis malgré IPP) | |
| Prise d’AINS avec symptômes | |

## 3. Vomissements

| Contexte | Causes à évoquer |
|---|---|
| **Matinaux, à jeun** | grossesse, alcoolisme chronique, **hypertension intracrânienne** (« en jet », céphalées), insuffisance rénale, médicaments / intoxication |
| **Post-prandiaux** | obstacle digestif (sténose pylorique, **occlusion / sub-occlusion du grêle**), gastroparésie |
| **Aigus** | gastro-entérite, urgence abdominale, HTIC, infarctus, acidocétose |

**Gastroparésie** : vidange gastrique retardée sans obstacle (nausées, vomissements, plénitude). Causes : idiopathique, puis **diabète** (1re cause identifiée), post-chirurgicale (vagotomie), médicaments (opiacés).

**Régurgitations ≠ vomissements** : la régurgitation est passive, sans effort (RGO, Zenker, achalasie).

## 4. À retenir

- Dyspepsie fonctionnelle = **chronique + endoscopie normale**.
- Pas d’endoscopie chez la personne jeune sans signe d’alarme.
- Vomissements matinaux : grossesse, alcool, **HTIC**, médicaments ; la sub-occlusion du grêle fait vomir après les repas.
