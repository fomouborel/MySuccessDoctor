## 1. Définitions

| Signe | Définition | Origine habituelle |
|---|---|---|
| **Hématémèse** | vomissement de sang | haute (en amont de l’angle de Treitz) |
| **Méléna** | selles noires, goudronneuses, malodorantes (sang **digéré**) | haute ; parfois grêle ou côlon droit si transit lent |
| **Rectorragie** | sang rouge par l’anus | basse ; **ou haute massive** (transit accéléré → signe de gravité) |

## 2. Causes d’hémorragie digestive haute

1. **Ulcère gastro-duodénal** : **première cause**.
2. Varices œsophagiennes ou gastriques (hypertension portale) ; gastropathie d’hypertension portale.
3. Œsophagite, érosions gastro-duodénales (AINS).
4. **Mallory-Weiss** (déchirure du cardia après vomissements).
5. Tumeurs ; **lésion de Dieulafoy** (artériole sous-muqueuse de gros calibre qui saigne à travers une petite érosion, **sans vrai ulcère**) ; angiodysplasies ; ectasies vasculaires antrales (« estomac en pastèque »).

## 3. Évaluer la gravité

> La gravité s’évalue sur les **paramètres hémodynamiques** : fréquence cardiaque, tension artérielle (et hypotension orthostatique), signes de choc (marbrures, extrémités froides, oligurie, troubles de conscience).

L’**hémoglobine initiale sous-estime** la perte (l’hémodilution prend des heures). La quantité de sang extériorisé est trompeuse. Scores : Glasgow-Blatchford (avant endoscopie), Rockall (après).

## 4. Prise en charge

1. **Réanimation** : 2 voies veineuses, remplissage, transfusion **restrictive** (cible Hb ≈ 7–8 g/dl, plus haut si coronarien), correction de la coagulation, arrêt des AINS / anticoagulants selon le contexte.
2. **IPP IV à forte dose** avant l’endoscopie (ulcère suspecté).
3. Si suspicion de varices (cirrhose) : **vasoactifs** (somatostatine / terlipressine) + **antibioprophylaxie**.
4. **Endoscopie dans les 24 h** (plus tôt si instable) : diagnostic + **hémostase endoscopique** (adrénaline + clips, coagulation) pour un ulcère ; **ligature élastique** pour des varices.
5. En cas d’échec : **embolisation** artérielle radiologique ou **chirurgie** ; pour les varices : **TIPS**.
6. Après : rechercher et éradiquer H. pylori, IPP, réévaluer les AINS.

## 5. Raisonner sur une vignette

> Femme âgée, selles noires, dyspnée d’effort, AINS récents : **ulcère hémorragique** jusqu’à preuve du contraire → **gastroscopie**. Si les selles noires **précèdent** la prise d’AINS de plusieurs semaines, ou si la gastroscopie est normale : penser au **cancer du côlon droit** → coloscopie. Une **perforation** ne donne pas de méléna (douleur brutale, contracture).

## 6. À retenir

- 1re cause : **ulcère** ; gravité = **hémodynamique** ; Hb initiale faussement rassurante.
- Méléna = sang digéré, origine **haute** le plus souvent.
- Traitement de 1re intention : **IPP IV + endoscopie thérapeutique** dans les 24 h.
