## 1. Iléus ou occlusion ?

| | **Occlusion mécanique** | **Iléus paralytique / réflexe** |
|---|---|---|
| Cause | **obstacle** (bride, hernie, tumeur…) | **paralysie** sans obstacle (post-opératoire, péritonite, pancréatite, colique néphrétique, hypokaliémie, opiacés) |
| Douleur | **crampes** par vagues | sourde, peu intense |
| Auscultation | **bruits métalliques**, péristaltisme de lutte (puis silence si évoluée) | **silence** |
| Air dans le rectum | **non** (en aval d’une occlusion complète) | **oui** |
| Communs | ballonnement, arrêt des matières et des gaz, vomissements, niveaux hydro-aériques | |

## 2. Occlusion du grêle

**Causes** : **bride** (1re cause chez l’opéré), **hernie étranglée** (inguinale, crurale, ombilicale, interne), tumeur, carcinose, Crohn (sténose), invagination (enfant ; chez l’adulte sur tumeur), iléus biliaire, corps étranger.
Sans antécédent chirurgical : une bride est très improbable → chercher une hernie, une tumeur, une carcinose.

**Clinique** : douleurs crampoïdes, **vomissements précoces** (occlusion haute), arrêt du transit parfois tardif, météorisme, tympanisme. Examiner les **orifices herniaires**.

**Biologie** : non diagnostique ; évalue le **retentissement** (déshydratation : urée, créatinine ; troubles ioniques) et l’ischémie (lactates, leucocytose).

**Imagerie** : **scanner** abdominal = examen de référence (siège, cause, **signes d’ischémie** : paroi qui ne se rehausse pas, pneumatose, épanchement).

## 3. Traitement

| Situation | Conduite |
|---|---|
| Occlusion **simple** (bride probable, pas de signe de gravité) | **traitement conservateur** : jeûne, **sonde naso-gastrique** en aspiration, perfusion, correction ionique, surveillance ; test au produit de contraste hydrosoluble |
| **Strangulation / ischémie** (douleur continue, fièvre, défense, tachycardie, lactates ↑, signes au scanner), hernie étranglée, échec à 48–72 h | **chirurgie urgente** |

Laxatifs et lavements n’ont **aucune** place dans l’occlusion du grêle.

## 4. Pièges

- « Pas d’air dans le rectum » → **occlusion**, pas iléus.
- Une **défense** n’est pas attendue dans une occlusion simple : elle signe une complication.
- « L’urée est LE signe biologique de l’occlusion » : faux, elle n’est ni constante ni spécifique.

## 5. À retenir

- Crampes + péristaltisme = **mécanique** ; silence + air dans le rectum = **iléus**.
- 1re cause d’occlusion du grêle = **bride**.
- Occlusion simple : **sonde gastrique + perfusion** ; gravité : **chirurgie**.
