## 1. Les deux cancers de l’œsophage

| | **Carcinome épidermoïde** | **Adénocarcinome** |
|---|---|---|
| Siège | tiers **supérieur et moyen** | tiers **inférieur**, jonction |
| Facteurs de risque | **alcool + tabac** (synergie), boissons très chaudes, **sténose caustique**, antécédent de **cancer ORL / bronchique**, achalasie | **RGO chronique → Barrett**, obésité, sexe masculin, tabac |
| Lésion précurseur | dysplasie malpighienne | **œsophage de Barrett** |
| Radiosensibilité | élevée | moindre |

Le cancer de l’estomac n’est **pas** un terrain de cancer de l’œsophage.

## 2. Œsophage de Barrett

- **Définition** : **métaplasie** glandulaire de type **intestinal** remplaçant l’épithélium malpighien du bas œsophage, conséquence du RGO chronique. *Métaplasie ≠ dysplasie.*
- Diagnostic : endoscopie (muqueuse « saumon ») + **biopsies** (protocole de Seattle).
- Risque d’adénocarcinome : faible par patient-année (ordre de grandeur cité dans les archives : 1 %/an ; risque relatif ×30 à ×125).
- Prise en charge :
  - sans dysplasie → IPP + **surveillance endoscopique avec biopsies** ;
  - dysplasie de **haut grade** / lésion visible → **résection endoscopique (mucosectomie)** puis **ablation par radiofréquence** (technique **endoscopique**) ;
  - cancer invasif → chirurgie.
- La **fundoplicature ne fait pas régresser** le Barrett.
- Le Barrett est **asymptomatique** en lui-même (pas de dysphagie).

## 3. Clinique

Souvent tardive : **dysphagie progressive** (solides → liquides), **régurgitations**, **amaigrissement / AEG**, odynophagie ; signes d’extension : dysphonie (nerf récurrent), toux à la déglutition (fistule œso-trachéale), hématémèse.

## 4. Bilan

1. **Endoscopie + biopsies** (diagnostic).
2. **Stadification cTNM**, indispensable à la décision thérapeutique :
   - **scanner** cervico-thoraco-abdominal (métastases) ± **TEP-scan** ;
   - **écho-endoscopie** (T et N locorégional) ;
   - **laparoscopie** de stadification pour les adénocarcinomes de la jonction (carcinose).
3. Carcinome épidermoïde : rechercher un **second cancer ORL / bronchique** (et inversement, endoscopie œsophagienne dans le bilan d’un cancer ORL).
4. **Bilan d’opérabilité** : nutritionnel (dénutrition fréquente), cardio-respiratoire, hépatique.

## 5. Traitement (schéma)

| Situation | Traitement |
|---|---|
| Superficiel **T1a N0** | **résection endoscopique** (mucosectomie / dissection sous-muqueuse) — **jamais si N+** |
| Localement avancé résécable | traitement **néo-adjuvant** (radio-chimiothérapie ou chimiothérapie péri-opératoire) **puis chirurgie** |
| Épidermoïde non opérable / cervical | radio-chimiothérapie exclusive |
| Métastatique (**M1**) | traitement **palliatif** (pas de chirurgie curative) ; prothèse en cas de dysphagie |

**Chirurgie** : œsophagectomie + curage ganglionnaire étendu, plastie gastrique (le côlon en alternative).
- **2 voies** (Lewis-Santy : abdomen + thoracotomie droite) pour le tiers inférieur ;
- **3 voies** (McKeown : abdomen + thorax + cou) pour les tumeurs plus hautes.

Contre-indications : envahissement de l’aorte / de la trachée (T4b), métastases, cirrhose décompensée, insuffisance respiratoire sévère.

**Jonction œso-gastrique — classification de Siewert** : I = bas œsophage ; II = cardia vrai ; III = sous-cardial.

> Le **« watch and wait »** après réponse complète est une stratégie du **cancer du rectum** : ce n’est pas le standard de l’adénocarcinome de la jonction.

## 6. Anatomo-pathologie

**Dysplasie de haut grade = néoplasie intra-épithéliale de haut grade** : atypies sur toute la hauteur de l’épithélium **sans franchissement de la membrane basale**. Franchissement → carcinome infiltrant.

## 7. À retenir

- Haut / moyen → **épidermoïde** (alcool-tabac, ORL, caustique) ; bas → **adénocarcinome** (Barrett).
- Barrett = **métaplasie** intestinale ; Nissen ne le guérit pas.
- Mucosectomie : **T1 N0 seulement**.
- Toujours un **cTNM** avant de décider.
